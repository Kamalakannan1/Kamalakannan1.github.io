Orders lakehouse with quality gates

I built a PySpark pipeline that takes about a million messy order rows through Bronze, Silver and Gold. Bad rows go to a quarantine table with the rules they broke, and a quality gate stops the run if too many fail.

To measure it, I generated synthetic data with 68,521 known defects hidden in 900,000 orders. The pipeline caught every one and rejected no good orders. Nine tests cover the rules, the layers and the gate.

View the code on GitHub

The data is synthetic, and every number below comes from one real run on a 2-core, 8 GB machine.
